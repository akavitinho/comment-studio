Política de Privacidade do Comment Studio

Versão local não comercial · Atualizada em 5 de novembro de 2026

Esta política explica como o Comment Studio trata informações quando você cadastra contas, usa campanhas e prepara ou publica vídeos. O responsável pelo aplicativo é [NOME DO RESPONSÁVEL]. Para dúvidas ou pedidos sobre seus dados, escreva para contato@exemplo.com.

1. Dados utilizados

O aplicativo usa os dados que você fornece ou autoriza: nome e identificador das contas de redes sociais, sessões de navegador, configurações de proxy, vídeos e legendas escolhidos, programações, resultados de publicação, histórico de ações e informações técnicas necessárias para diagnosticar falhas. Ao conectar um perfil profissional do Instagram, recebe seu identificador, nome de usuário e token de autorização da Meta.

2. Finalidades

Esses dados são usados para abrir as contas cadastradas, aplicar a conexão ou o proxy selecionado, executar as funções que você inicia, organizar filas, publicar Reels autorizados, mostrar o andamento e evitar envios duplicados. O teste opcional de proxy consulta o IP de saída e uma estimativa de localização.

3. Onde os dados ficam e com quem são compartilhados

Cadastros, configurações, sessões e histórico ficam no computador em que o Comment Studio é executado. Tokens do Instagram, sessões de armazenamento e credenciais de proxy são protegidos pelo mecanismo de credenciais do Windows usado pelo aplicativo.

Para publicar um Reel, o vídeo escolhido é enviado temporariamente a um armazenamento privado no Supabase. Uma URL temporária permite que a Meta obtenha o arquivo para processar a publicação. O aplicativo também se comunica com a Meta para autorização e publicação; a troca do código de autorização é processada por uma função do Supabase. As plataformas acessadas pelo aplicativo, o Supabase e o fornecedor de proxy escolhido por você tratam os dados recebidos conforme suas próprias políticas. Ao testar um proxy, serviços de consulta de IP e localização podem receber o IP de saída.

4. Conservação e exclusão

Os registros locais permanecem no computador enquanto você mantiver os dados do aplicativo. Ao desconectar o Instagram, o token local dessa conta é removido e a fila é pausada. Ao excluir uma conta, seus itens pendentes são cancelados; registros de publicações anteriores podem permanecer no histórico local.

O aplicativo tenta remover o vídeo temporário do Supabase após a confirmação da publicação. Também tenta limpar arquivos antigos após 48 horas enquanto estiver aberto. Se houver falha de rede ou o aplicativo permanecer fechado, a remoção pode depender de nova execução ou intervenção do responsável. Publicações já feitas no Instagram devem ser removidas na própria plataforma.

5. Suas escolhas e direitos

Você escolhe quais contas conectar, quais arquivos enviar, quando iniciar ou pausar a fila e se usará um proxy. Pode desconectar o Instagram pelo aplicativo. Para solicitar informações, correção ou exclusão de dados sob responsabilidade do Comment Studio, escreva para contato@exemplo.com, identificando a conta relacionada ao pedido. Solicitações serão avaliadas conforme a legislação aplicável.

6. Segurança e alterações

O aplicativo restringe o acesso a tokens na interface, protege credenciais locais e usa conexões HTTPS nas integrações de publicação. Nenhum sistema elimina completamente o risco de falhas; mantenha o Windows e o aplicativo atualizados e proteja o acesso ao computador. Esta política pode ser atualizada quando as funções ou integrações mudarem; a data acima indicará a versão vigente.
